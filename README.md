# Arkanoid

 Игра Arkanoid на HTML5 + CSS3 + JavaScript + PixiJS.


![Демо](./assets/demo.gif)

## Управление

| Клавиша | Действие |
|---|---|
| `←` / `A` | Ракетка влево |
| `→` / `D` | Ракетка вправо |
| `SPACE` | Старт игры / запуск мяча / рестарт |
| `ESC` | Пауза |

## Как запустить

**Вариант 1 — Live Server (VS Code):**
1. Открыть папку проекта в VS Code.
2. Правый клик по `index.html` → **Open with Live Server**.

**Вариант 2 — любой HTTP-сервер:**
```bash
python3 -m http.server 8080
Открыть http://localhost:8080.

Важно: ES-модули и импорт PixiJS через importmap требуют HTTP-сервера. Открытие index.html двойным кликом (file://) не сработает.

Технологии
PixiJS v8 — рендеринг графики, игровой цикл через ticker.

Web Audio API — звуки генерируются программно, без аудиофайлов и внешних библиотек.

ES6 Modules — организация кода через import/export, никаких сборщиков.

Importmap — подключение PixiJS через CDN без npm и сборки.

Архитектура
text
js/
├── main.js                  # точка входа
├── ArkanoidGame.js          # главный класс: слои, состояния, игровой цикл
├── entities/                # сущности (что существует в мире)
│   ├── Paddle.js
│   ├── Ball.js
│   └── Brick.js
├── systems/                 # системы (что происходит между сущностями)
│   ├── InputSystem.js       # клавиатура с edge-detection и cleanup
│   ├── CollisionSystem.js   # AABB-коллизии, penetration depth
│   ├── LevelBuilder.js      # генерация уровня
│   ├── Hud.js               # очки, жизни, уровень
│   └── SoundSystem.js       # ретро-звуки на Web Audio API
└── utils/
    └── constants.js         # единый источник правды: размеры, цвета, физика
Ключевые решения:

Разделение на слои world и hud в Pixi — тряска экрана двигает только world, HUD стоит на месте.

Сущности не знают друг о друге — все коллизии в CollisionSystem, сущности не импортируют друг друга.

Определение стороны удара по блоку через penetration depth — решает проблему залипания мяча в углах.

Угол отскока мяча зависит от точки удара по ракетке — как в оригинале, ±60°.

Ограничение максимальной скорости мяча (MAX_SPEED = 11) — предотвращает туннелирование сквозь ракетку при длительной игре.

Функционал изолирован в классе ArkanoidGame — снаружи виден только экземпляр, есть метод destroy() для полной выгрузки.

Особенности реализации
Состояния игры: MENU, PLAYING, PAUSED, GAME_OVER, VICTORY.

Три жизни, счёт за каждый разбитый блок, номер уровня в HUD.

Бронированные блоки (hp: 2) в верхних двух рядах — требуют двух попаданий. При первом ударе блок вспыхивает белым.

Анимации: разрушение блока через scale+alpha, тряска экрана при потере жизни, вспышка при ударе по hp:2.

Ретро-звуки: удар по ракетке, разрушение блока, потеря жизни, победа, поражение.

### Как записать на Windows

**Вариант А (рекомендую): ScreenToGif**

1. Скачай бесплатно: `screentogif.com`.
2. Установи, запусти.
3. **Recorder** → **New**.
4. В настройках поставь **FPS: 15–20**, размер окна — область игры (не весь экран).
5. Нажми **Record**. Открой игру в браузере, нажми SPACE, поиграй 10–15 секунд.
6. **Stop** → откроется редактор.
7. Обрежь лишнее, убери первую/последнюю секунду.
8. **File → Save as → GIF** → сохрани как `demo.gif`.
9. Положи файл в `assets/` проекта.

**Вариант Б: Xbox Game Bar (встроен в Windows 10/11)**

- `Win + G` — открывает Game Bar.
- **Capture** → **Record** — записывает видео.
- Получишь `.mp4`. Конвертируй в GIF через онлайн-сервис (например, `ezgif.com/video-to-gif`) или через `ffmpeg`:
```bash
ffmpeg -i demo.mp4 -vf "fps=15,scale=800:-1" -loop 0 demo.gif
Что показать в GIF (10–15 сек):

Меню (ARKANOID + Press SPACE).

Пробел → игра.

Пара попаданий по блокам — видно разрушение.

Промах — видно тряску и HUD.

(Опционально) Разбить все блоки → VICTORY.

Оптимальные параметры GIF:

Разрешение: 800×600 (размер canvas).

FPS: 15–20 (больше — файл тяжелеет).

Длительность: 10–15 секунд.

Размер файла: до 5 МБ — если больше, уменьши FPS или длительность.
